Help & Documentation

Everything you need to know about setting up Gmail SMTP, previewing with dynamic ephemeral ports, and ensuring direct Primary Inbox delivery.

1. Gmail SMTP Setup (16-Character Google App Password)

Google requires a dedicated 16-character App Password for third-party email clients to authenticate with Gmail SMTP on Port 465 SSL.

1

Enable 2-Step Verification on your Google Account

Navigate to Google Account Security. Ensure 2-Step Verification is activated.

2

Generate an App Password

Search for "App Passwords" or visit myaccount.google.com/apppasswords. Name your app "MailCraft" and click Create.

Generated format: xxxx xxxx xxxx xxxx (16 lowercase letters)
3

Configure MailCraft Deploy Screen

In the MailCraft app, navigate to the Deploy & Send tab. Enter your Gmail address and paste the 16-character App Password into the sender credentials card.

⚡

2. Dynamic Ephemeral HTTP Server Preview

When you press the green ▶ Run button in the HTML Workstation, MailCraft launches an embedded local HTTP server.

Collision-Free Random Port Architecture

Unlike typical servers that lock common ports like 8080 or 3000, MailCraft delegates port assignment to the OS kernel using ephemeral sockets (ports 49152 – 65535, e.g. 63823). Every preview session receives a fresh random port. Swiping down or closing the preview modal terminates the server socket immediately.

📥

3. Direct Primary Inbox Routing (Bypassing Promotions & Spam)

MailCraft enforces specific RFC guidelines to maximize delivery to the recipient's primary inbox:

  • RFC 2076 Precedence: Sets Precedence: personal to signal person-to-person communication rather than bulk marketing.
  • Clean MIME Structure: Generates balanced multipart/alternative content without tracking pixels or bulk unsubscribe markers.
  • Direct SSL Gateway: Connects directly to smtp.gmail.com:465 with full TLS handshaking.
