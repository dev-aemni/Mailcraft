HTML Workstation

Code emails like a pro with line numbers gutter, syntax formatting, tag helpers, and instant reset capabilities.

Direct Primary Inbox

Import images, PDFs, and local HTML files directly from device storage with automatic Base64 encoding.

White Neumorphism & Dark Mode

Clean, tactile soft UI design system that seamlessly adapts to system dark theme with perfect high-contrast inversion.
