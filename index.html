✉️ MailCraft

Native Android HTML Email Studio • Direct Primary Inbox SMTP Client

Download APK (v1.1.1) Setup Guide Request Features

🚀 Built For Serious Email Crafting

MailCraft is a native Android application designed to craft, preview, and dispatch pixel-perfect responsive HTML emails directly to recipients' Primary Inboxes without cloud intermediary servers.

⚡ Random Port Server

Runs a real-time local HTTP preview server on dynamic ephemeral ports (e.g. 63823), avoiding port collisions and shutting down automatically on exit.

📬 Primary Inbox Routing

Utilizes RFC Precedence headers, auto-injected plain-text multiparts, and clean SMTP formatting to bypass Spam and Promotions tabs.

🎨 Native Code Studio

Full-fledged code workstation with live syntax highlighting, HTML block builders, template library, and dark/light client simulation.

🤖 MailCraft AI Studio

Built-in AI assistant capable of generating templates, auditing HTML for Outlook/Gmail compatibility, and diagnosing SMTP deliverability.

📱 Live Workstation & Real-time Preview

Write raw HTML in the native code editor and see it rendered immediately in our sandboxed WebView engine:

<!DOCTYPE html>
<html>
  <body style="margin:0; padding:20px; font-family:sans-serif; background:#f4f7fa;">
    <div style="max-width:560px; margin:auto; background:#ffffff; border-radius:12px; padding:24px;">
      <h1 style="color:#1e1b4b; font-size:20px;">Welcome to MailCraft! 🚀</h1>
      <p style="color:#475569; font-size:14px; line-height:1.5;">Sent directly from Android via Gmail SMTP with RFC 5322 compliance.</p>
    </div>
  </body>
</html>
From: <sender@gmail.com> • To: <recipient@domain.com>

Welcome to MailCraft! 🚀

This email was delivered straight to the Primary Inbox utilizing direct TLS encryption and client-side MIME packaging.
