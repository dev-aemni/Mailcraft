🔑 Generating Your 16-Character Gmail App Password

Google requires a 16-character App Password for secure SMTP transmission from 3rd-party apps (your regular account password will be rejected by Google's SMTP servers).

1

Enable 2-Step Verification

Navigate to your Google Account security settings at myaccount.google.com/security and ensure 2-Step Verification is turned ON.

2

Create an App Password

Search "App Passwords" in the Google Account search bar, or visit myaccount.google.com/apppasswords. Name it MailCraft Android.

3

Copy the 16 Letters into MailCraft

Google will generate a 16-letter code (e.g. abcd efgh ijkl mnop). Paste this directly into the Deploy & Send screen in MailCraft. Your password stays stored in device EncryptedSharedPreferences only.

📬 Primary Inbox Delivery Guarantee

How MailCraft ensures your emails land straight in the recipient's primary inbox:

1. RFC Precedence Headers: Automatically injects standard RFC personal message precedence indicators so email providers classify it as 1-on-1 personal communication.

2. Auto Multipart Generation: Concurrently builds clean plain-text alternatives alongside rich HTML to maximize deliverability scores.

3. Clean MIME Boundary Headers: Strictly formats boundary tokens preventing spam heuristic triggers.

🌐 Dynamic Ephemeral Port Server

When you click ▶ Run in the workstation:

• MailCraft spins up an internal multi-threaded HTTP server using ServerSocket(0) on 127.0.0.1.

• The OS kernel assigns an available high-range random port (e.g. 63823), preventing any port collision with development environments like 8080 or 3000.

• The server socket shuts down automatically the exact moment you dismiss or swipe down the preview sheet.
